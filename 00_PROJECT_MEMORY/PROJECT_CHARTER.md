# NEWMODEL — Project Charter
Version: 1.0
Status: ACCEPTED
Date: 2026-10-04

## Purpose
Build NEWMODEL as a real, evolving web product through disciplined human–AI collaboration.

## Product identity
NEWMODEL is currently the project/repository identity. Product definition must be governed by accepted vision and architecture artifacts, not by repository name alone.

## Collaboration contract
Human = Product Owner / final decision authority.
AI = thinking partner, architect, product strategist, UX thinker, senior engineer and challenger.

## Core development loop
Think → Model → See → Challenge → Change → Build → Test → Learn.

## Non-negotiables
- No silent architectural decisions.
- No invented business data.
- No presenting assumptions as facts.
- No Big Bang implementation.
- Visualize important product concepts before large implementation.
- Existing specialist systems remain authoritative for their specialist capabilities unless explicitly replaced.
- GitHub records accepted project truth; Chat remains the workshop.
- Prototype is a thinking instrument.
- Architecture evolves explicitly and historically.

## Current status
The project is in architecture/product-definition evolution. The repository is the engineering memory and implementation record.
